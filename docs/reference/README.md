# 参考图说明

本目录的 4 张图片是设计阶段使用的 **UI 参考截图**，取自 macOS 上的一款系统监控面板，
仅用于记录本项目的界面结构来源：

| 文件 | 内容 |
| --- | --- |
| `01-overview.png` | 概览页：左侧设备示意图 + 右侧指标卡片，下方进程与服务状态 |
| `02-performance-power.png` | 性能与电源：CPU/GPU 曲线、温度、功耗、内存构成 |
| `03-network-disk.png` | 网络与磁盘：上下行速率、连接表、Wi-Fi 信号与邻频 |
| `04-services.png` | 服务：远程服务器延迟、容器列表、监听端口表 |

本项目只是**借用其布局与信息密度**作为参考，代码与实现完全独立；
概览页也按要求做了改动（去掉设备示意图、指标曲线铺满上半部分）。
